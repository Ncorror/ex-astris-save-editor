# Ex Astris Save Editor v1.8.1

## Changes

- The header card on the **Items** tab now shows **Find save** once Root or Shizuku is connected, and **Switch** when a game save is open. Previously the button disappeared after connecting, and the save could only be found from the **Save** tab.
- The README now states that the MIT License covers the source code only. Item icons and game-derived item texts belong to their owners.

Everything from v1.8.0 is unchanged. The Arknights skins for Hime and MsBlack are still patched on your phone, and the app contains no game files.

## Checked on a device

- Connect / Find save / Switch in the header card, with both Root and Shizuku.
- Arknights skins on and off, in the world, menus, hub scenes and battle.
- Saving item changes (the game shows the edited quantities).
